# Untangle 디자인 안내 v0.2 — "실타래" 테마

`tokens.css`와 함께 쓴다. 앱은 처음 화면, 오늘, 현재 토픽, 토픽 보드, 지난 토픽으로 나뉜다. `/kit`에서 실제 부품과 가상 예시를 살펴볼 수 있다.

## 1. 한 줄 요약

엉킨 선이 풀려 가지런해진다. 그림은 선 하나로만 그리고, 화면은 조용하게, 첫 카드 한 장만 크게.

## 2. 원칙

1. **한 화면에 주인공은 하나.** 오늘에서는 첫 제안 카드다. 초안과 동작은 카드 안에 있고 화면 아래 장식 문구는 두지 않는다.
2. **실 색은 장식에만 쓴다.** 테마 실 색(`--thread-N`)을 `--thread-current`로 토픽의 짧은 선과 카드 선 그림에 전달한다. 글자·링크·별·아이콘은 잉크색이며 본문 속 링크에만 밑줄을 친다. 별도 강조색은 없다.
3. **제안 입력만 제한한다.** 카드 생성에 보내는 토픽만 최대 9개, 제안은 최대 3장, 별은 최대 3개다. 전체 토픽 목록이나 사용자가 옮긴 활성 토픽의 개수는 제한하지 않는다. 파서의 기존 분류 규칙은 그대로 둔다.
4. **재촉하지 않는다.** 빨간 경고, 진행률 막대, 연속 기록을 쓰지 않는다. 지난 날짜도 보조 글자색으로 표시한다.
5. **그림은 선만.** 굵기 2px, 끝이 둥근 선. 면을 칠한 그림, 그라데이션, 그림자, 이모지를 쓰지 않는다.

## 3. 화면의 흐름

카드에서 ‘시작’을 누르면 머리줄과 다른 카드 위를 완전히 덮는 집중 화면을 연다. 제목, 체크·원문 편집 가능한 초안, ‘먼저 이것만’, ‘다 했어요’, ‘나가기’에 집중한다. Esc·‘나가기’는 진행 중 상태와 초안을 유지하고, 닫힌 뒤 원래 카드로 초점을 돌린다. 완료하면 기존 완료 기록에 남기고 돌아온다.

| 화면 | 경로 | 구성 |
|---|---|---|
| 처음 화면 | `/welcome` | 머리줄 없이 가운데에 선 그림, 72px `untangle`, 영문 소개 `Every knot gives way, one thread at a time.`, 한글 소개 `흩어진 일을 풀어, 오늘의 한 걸음으로.`와 두 시작 버튼을 놓는다. ‘샘플로 둘러보기’는 두 가상 인물 선택을 펼치고 ‘내 기록으로 시작하기’는 `/start`로 이동한다. |
| 오늘 | `/` | 가운데 한 열의 최대 폭은 880px. 화면 폭 1280px 이상에서 다른 카드가 있으면 왼쪽에 첫 카드, 오른쪽 약 360px 열에 ‘다른 한 걸음’을 놓는다. 그보다 좁으면 한 열로 첫 카드 아래에 다른 카드를 둔다. `One thread at a time.` 제목 아래 별도 토픽 목록은 두지 않는다. |
| 현재 토픽 | `/topics` | 테마별 제목 아래에 각 토픽을 독립 상자로 놓는 반응형 그리드다. 상자 전체를 누르면 보드로 이동하고 별·메뉴는 따로 누른다. 토픽 이름에는 밑줄을 치지 않는다. 설명은 두 줄까지만 표시하고 출처는 표시하지 않는다. 나중에 볼 토픽도 이 화면에서 꺼낸다. |
| 토픽 보드 | `/topics/[id]` | 제목 바로 아래에 그 토픽의 제안을 놓는다. 그 아래의 정보는 한 열이며 ‘지금 상태’, ‘다음 할 일’, ‘막힌 점’만 기본으로 보인다. 목표·산출물·결정·관련 주제·출처·일정·메모는 ‘더 보기’에 접는다. |
| 지난 토픽 | `/done` | 완료한 카드의 제목·토픽 이름·메모를 완료 날짜별로 묶고 최신 날짜부터 보여준다. |

로비를 제외한 앱 상단에는 선 그림만 있는 로고와 `오늘`, `현재 토픽`, `지난 토픽` 메뉴를 둔다. 로고 링크는 접근성 이름 `Untangle 처음 화면`으로 `/welcome`에 연결한다. 현재 메뉴 아래에만 잉크색 선을 두고 600 굵기로 표시하며 글자에는 밑줄을 치지 않는다. 톱니 아이콘으로 설정을 연다. 밝기·글자 크기·움직임 줄이기·하루 카드 수·백업·모두 지우기·내보내기 프롬프트 다시 복사는 설정에 둔다. 설정은 브라우저에 저장하고 밝기·글자·움직임은 첫 그리기 전에 적용한다. 크게는 모든 글자 토큰의 1.12배이며 하루 카드 수는 받은 카드의 표시 개수만 제한한다. 온보딩의 `샘플로 둘러보기`는 머리줄 오른쪽에 두고 선택기는 그 아래에서 펼친다.

`/`에 들어왔을 때 저장된 토픽이 없으면 `/welcome`으로 이동하고 카드를 생성하지 않는다. 개인·샘플 어느 모드든 저장된 토픽이 있으면 기존 오늘 화면을 유지한다.

토픽 보드는 열기만 해서는 카드를 생성하지 않는다. 카드가 없을 때 버튼으로 그 토픽 하나만 요청한다. 나중에 둔 토픽도 명시 요청할 수 있고 저장된 활성·나중에 분류는 바꾸지 않는다. 오늘의 자동 선정은 계속 활성 토픽만 사용하며, 수락하고 아직 끝내지 않은 카드가 있는 토픽은 두 요청 모두에서 제외한다.

‘지금 상태’와 ‘다음 할 일’ 옆 연필을 누르면 그 자리에서 편집한다. 다음 할 일은 한 줄에 한 항목을 쓴다. 저장하면 localStorage에 반영하고 다음 카드 생성 입력에도 고친 값을 쓴다. 빈 상태와 빈 목록도 저장할 수 있다. 취소하면 기존 값을 유지하고, 저장에 실패하면 입력 내용을 지우거나 편집을 닫지 않는다.

## 4. 색과 글꼴

글꼴은 공식 npm 패키지 `pretendard`의 가변 글꼴을 `next/font/local`로 직접 제공한다. 외부 글꼴 CDN은 사용하지 않는다. 본문은 400, 보조 강조는 500, 라벨·버튼은 600, 제목은 700이다. 글꼴 저작권과 SIL OFL 1.1 원문은 `public/licenses/Pretendard-LICENSE.txt`에 둔다. 설치·사용법은 [공식 Pretendard 안내](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/README.md), 재배포 조건은 [공식 라이선스](https://github.com/orioncactus/pretendard/blob/main/LICENSE)를 따른다.

표시용 글꼴은 npm 패키지 `@fontsource/instrument-serif`의 Instrument Serif를 `next/font/local`로 직접 제공하며 `--font-display`로 참조한다. **한 화면에 한 곳만 쓴다.** 오늘 화면에서는 영어 제목 `One thread at a time.` 한 곳에 40px 안팎의 기울임꼴을 쓴다. 처음 화면에서는 72px 정체 `untangle`과 기울임꼴 영문 소개를 하나의 가운데 브랜드 묶음으로 사용한다. 머리줄 로고는 글자 없이 선 그림만 두며 한글·버튼·나머지 본문은 Pretendard를 유지한다. 400 굵기의 정체·기울임꼴을 제공하며 SIL OFL 1.1 라이선스는 `public/licenses/Instrument-Serif-LICENSE.txt`에 동봉한다.

글자 크기는 `--text-xs` 13px, `--text-sm` 14px, `--text-md` 16px, `--text-lg` 17px, `--text-xl` 21px, `--text-2xl` 40px다. 초안의 미리보기 본문과 원문 편집은 `--text-draft` 15px를 쓴다. 가운데 열은 `--content-width-today` 880px, 넓은 오늘 화면의 오른쪽 카드 열은 `--today-aside-width` 360px다.

| 역할 | 밝은 모드 | 어두운 모드 |
|---|---|---|
| 바탕 / 카드 면 / 초안 면 | `#FAFAF8` / `#FFFFFF` / `#F3F2EE` | `#161614` / `#1E1E1C` / `#262623` |
| 본문 / 보조 글자 / 잉크 바탕 위 글자 | `#1C1C1A` / `#5C5C57` / `#FFFFFF` | `#EDEBE6` / `#A8A59D` / `#161614` |
| 기본 선 / 보조 버튼 선 / 점선 | `#E7E5E0` / `#C9C6BF` / `#96938B` | `#33322E` / `#4A4843` / `#6E6B64` |
| 실 1~4 | `#3A5BC7` / `#1F8A70` / `#D9722E` / `#C2477F` | `#7C9BFF` / `#4FC3A1` / `#F0965A` / `#E57FAE` |
| 실 5~8 | `#7A52C7` / `#B08A1E` / `#C24B3A` / `#5A6B7F` | `#A98BEE` / `#D4B24A` / `#EE8272` / `#9AA9BC` |

기본은 기기의 `prefers-color-scheme` 설정을 따른다. 머리줄에서 바꾼 선택은 `localStorage`에 저장하고 다음 방문에도 유지한다. 저장한 선택은 첫 화면을 그리기 전에 적용하며, 저장값이 없을 때도 어두운 기기 설정에 맞는 CSS를 먼저 적용해 밝은 화면이 잠깐 번쩍이지 않게 한다. 주요 버튼은 두 모드 모두 `--color-ink` 바탕과 `--color-on-ink` 글자를 쓴다. 따라서 어두운 모드에서는 밝은 버튼에 어두운 글자를 표시한다.

컴포넌트에서는 이 값을 직접 쓰지 않고 토큰을 참조한다. 큰 모서리는 16px, 강조 테두리는 1.5px다. 제목과 본문은 `word-break: keep-all`, 긴 영문은 `overflow-wrap: anywhere`로 감싼다.

## 5. 선 그림

| 곳 | 모양 | 움직임 |
|---|---|---|
| 로고 | 왼쪽이 엉키고 오른쪽이 곧은 짧은 선 | 없음 |
| 처음 화면 | 원본 온보딩의 엉킨 경로와 `M230 60H986` 꼬리 경로, 2px 둥근 선 | 들어올 때 1200ms 동안 한 번 그려짐. 앞 65%는 엉킨 부분, 뒤 35%는 곧은 꼬리. 움직임 줄이기에서는 완성된 선만 표시 |
| 온보딩 확인 화면 | 엉킨 잉크색 선이 테마 수만큼의 색 선으로 갈라져 곧게 뻗음 | 화면에 들어올 때 한 번, 왼쪽에서 오른쪽으로 그려짐 (`--motion-thread`, 300ms 이하) |
| 첫 카드의 오른쪽 위 | 로고와 같은 모양의 긴 선 | 카드를 완료하면 엉킨 부분이 곧게 펴짐 |
| 빈 화면과 로딩 | 곧은 선 한 줄 (로딩 중에는 그려졌다 사라짐을 반복) | 로딩 중에만, 한 주기는 `--motion-fast` |

로고 선 (viewBox `0 0 44 24`):

```
M2 14c3-10 9 8 5-2s8-9 7 0 6 6 5 0c-1-5 4-4 5 0h18
```

첫 카드 선 (viewBox `0 0 150 28`):

```
M2 16c4-14 12 10 7-3s11-12 9 1 8 8 7 0c-1-7 6-6 7 0 1 5 6 2 8 0h108
```

온보딩 선 (viewBox `0 0 1000 110`, 굵기 2.5):

```
엉킨 선(잉크색): M14 60c18-52 52 40 30-14s46-50 40 6 34 36 30-4c-4-34 28-30 32 2 3 26 30 14 22-10s30-24 34 4c3 20 18 16 28 16
위 선(thread-1):  M230 60c50 0 50-36 110-36h646
가운데(thread-2): M230 60h756
아래 선(thread-3): M230 60c50 0 50 36 110 36h646
```

테마가 4개 이상이면 갈라지는 선을 같은 방식으로 늘린다. 그려지는 움직임은 `stroke-dasharray`와 `stroke-dashoffset`으로 만든다.

위 세 원본 경로는 바꾸지 않는다. 토픽 보드 머리 상자에는 선 그림을 두지 않고 제안 카드에만 카드 선 그림을 둔다. 테마 실은 토픽 이름 옆의 짧은 선과 테마 제목·탭에도 쓸 수 있다. 아이콘은 별도의 2px 둥근 선으로 그리고 채우지 않는다.

## 6. 부품

| 부품 | 모양 |
|---|---|
| 주요 버튼 | 온보딩 등에서 높이 `--button-primary`, 바탕 `--color-ink`, 글자 `--color-on-ink` 600, 모서리 `--radius-md`. 한 화면에 하나만 |
| 보조 버튼 | 높이 `--button-primary` 또는 `--touch-min`, 테두리 `--color-border-strong`, 바탕 없음 |
| 글자 버튼 | 바탕과 테두리 없음, 글자 `--color-ink` 600 |
| 카드 시작 | 가운데 정렬한 `시작` 주요 버튼. `--color-ink` 바탕, `--color-on-ink` 글자, 높이 `--button-primary`, 모서리 `--radius-md` |
| 아이콘 버튼 | 누르는 영역 44×44px, 20px 아이콘, 2px 둥근 선. `aria-label`, `title`, 포인터·키보드 초점 툴팁으로 이름을 제공 |
| 실 표시 | 가로 16px, 세로 3px, 모서리 2px, 테마의 실 색. 토픽 이름 왼쪽에 둔다 |
| 첫 카드 | `--color-surface` 바탕, 테두리 1.5px `--color-ink`, 모서리 16px, 안쪽 여백은 간격 토큰. 메타는 토픽 이름과 시간만, 제목 아래 행동 설명은 기본 접힌 `왜?` 안에 둠 |
| 작은 제안 카드 | `--color-surface` 바탕, 테두리 1px `--color-border`, 모서리 `--radius-lg` |
| 탐색 카드 (이런 것도 있어요) | `--color-surface` 바탕, 점선 테두리 1.5px `--color-border-loose` |
| 초안 상자 | 바탕 `--color-surface-sunken`, 모서리 `--radius-md`. `초안` 라벨은 한 번만, 오른쪽에 복사·고치기 아이콘. GFM 표·체크리스트·원문 편집을 지원 |
| 표 | 머리줄 아래 강조 굵기 잉크색 선, 줄 사이 1px `--color-border` |
| 테마 탭 | 잉크색/보조색 글자, 아래에 테마 실 색 선. 선택된 탭은 잉크색 선과 600 글자 |
| 토픽 줄 | 최소 높이 44px, 실 표시 + 이름 + 남은 날짜. 별 표시는 잉크색이며 테마 실 색으로 글자를 칠하지 않음 |
| 묶음 (확인 화면) | "지금 할 일"은 1.5px 잉크색 테두리, "나중에"는 1px 테두리, "정리해도 될 것"은 점선 테두리 |

`왜?`는 기본 접힘이다. 펼치면 이유 → 행동 설명 → 참고 근거 순서로 보여준다. 카드 동작 줄의 왼쪽에 시작·나중에·관심 없어요를 순서대로 놓고 다른 AI에서 이어가기 아이콘만 오른쪽 끝에 둔다. 이어가기 메뉴는 이 줄에 한 번만 두고 Claude/ChatGPT 선택 동작을 유지한다. 버튼 글자에는 밑줄을 치지 않는다. 온보딩 확인의 활성·나중에·삭제 중 현재 상태만 굵게 표시한다.

## 7. 화면 문구

- 홈 제목: "One thread at a time."
- 홈 제목 옆 오늘의 실: 표시할 카드 수만큼 작은 엉킨 선을 놓고, 해당 카드를 완료하면 같은 자리의 실을 곧게 편다. 완료 뒤 다른 카드로 자리를 채우지 않으며 새 제안을 받으면 새 카드 묶음을 따른다. 실 색은 해당 토픽을 따른다.
- 카드 메타: 토픽 이름과 "N분"만. focus/explore는 실선·점선으로 구분하고 별도 구분 라벨은 표시하지 않는다.
- 카드 버튼과 아이콘 이름: "시작", "나중에", "관심 없어요", "다 했어요", "다른 AI에서 이어가기"
- 초안: "초안", "복사", "고치기", "미리보기", "먼저 이것만", "왜?"
- 확인 화면: "프로젝트 N개를 찾았어요", "먼저 세 묶음으로 나눠 봤어요. 틀린 것만 옮기면 돼요.", "지금 할 일", "나중에", "정리해도 될 것", "이대로 시작"
- 저장 안내: "내용은 이 브라우저에만 저장돼요."
- 오늘 첫 방문 안내는 한 번만 세 줄로 표시한다: "카드는 먼저 건네는 한 걸음", "초안은 고쳐 쓰면 됨", "관심 없으면 ×". 닫기 버튼을 제공한다.
- 토픽 위쪽 검색은 이름·한 줄 설명으로 즉시 거른다. 검색 중에는 일치하는 접힌 묶음도 임시로 펼치고 검색을 지우면 저장된 접힘 상태로 돌아간다.
- 별 토픽은 맨 위 ‘고정’ 구역에 모으고 원래 테마·나중에 구역에는 중복 표시하지 않는다. 별 아이콘은 해당 토픽의 실 색으로 채우며 최대 세 개다. 네 번째를 누르면 ‘별은 세 개까지예요’ 알림을 띄운다.
- 펼침 메뉴는 페이지 최상위 층에 하나만 표시한다. 아래 공간이 부족하면 위로 열고, 바깥 클릭·Esc로 닫는다. 열린 동안 토픽 상자의 떠오름을 멈춘다. 토픽 보드와 다른 AI 이어가기·자료 메뉴에도 같은 방식을 쓴다.
- 초안의 복사 아이콘 옆에 내려받기를 둔다. 현재 원문을 Markdown 파일로 저장하며 다른 아이콘과 같은 44px 누름 영역·2px 둥근 선·이름표를 쓴다.
- 없는 주소는 가운데 엉킨 선 그림과 "오늘로 돌아가기" 버튼을 둔다.
- 되돌리기 알림: "'{토픽 이름}'을 나중으로 옮겼어요. 되돌리기"

존댓말 "~요"체, 짧게. 사용자를 평가하거나 재촉하는 표현은 쓰지 않는다.

## 8. 상태 화면

| 상태 | 모양 |
|---|---|
| 카드 생성 중 | 내용에 맞춘 작은 뼈대, 안에 그려졌다 사라지는 곧은 선과 "초안을 준비하고 있어요". 불필요한 고정 높이는 없음 |
| 카드 0장 | 곧은 선 한 줄, "오늘은 새로 권할 게 없어요.", "새 제안 받기" 버튼 |
| 오류 | 카드 자리에 "제안을 가져오지 못했어요.", "다시 시도" 버튼. 빨간색을 쓰지 않는다 |
| 완료 직후 | 카드의 엉킨 선이 곧게 펴진 뒤 카드가 사라지고 다음 카드가 첫 카드 자리로 올라온다 |

일반 화면의 움직임은 `--motion-fast`를 사용하거나 300ms 이하로 끝낸다. 처음 화면의 첫 선 그림만 1200ms 한 번 그리기를 예외로 둔다. `prefers-reduced-motion: reduce`에서는 애니메이션·전환·이동 대기를 끄고 처음 화면도 완성된 선만 보여준다.

| 동작 | 움직임 |
|---|---|
| 카드 등장 | 아래 8px 위치에서 제자리로 올라오며 나타남 |
| 나중에 / 관심 없어요 | 현재 카드가 옆으로 빠진 다음 저장 상태를 바꾸고 다음 카드를 올림 |

| 카드 생성 중 | 곧은 선을 그렸다 지우는 짧은 주기를 반복 |
| 체크리스트 | 체크할 때 체크 선이 그려짐 |

## 9. 접근성

- 누를 수 있는 것은 모두 `<button>`이나 `<a>`, 최소 44px.
- 글자 대비 4.5:1 이상. 보조 글자색은 `--color-text-secondary`보다 밝게 쓰지 않는다.
- 선 그림은 장식이므로 `aria-hidden="true"`.
- 움직임은 `prefers-reduced-motion`에서 끈다 (`tokens.css`에 반영됨).

WCAG 상대 휘도로 계산한 실제 글자 조합은 다음과 같다. 두 모드 모두 4.5:1을 넘으며 지정 색을 조정할 필요가 없었다.

| 모드 | 글자 | 화면 바탕 | 카드 면 | 초안 면 | 잉크 바탕 |
|---|---|---:|---:|---:|---:|
| 밝음 | 잉크색 | 16.33:1 | 17.07:1 | 15.24:1 | 사용하지 않음 |
| 밝음 | 보조 글자색 | 6.43:1 | 6.72:1 | 6.00:1 | 사용하지 않음 |
| 밝음 | 잉크 바탕 위 글자 | 사용하지 않음 | 사용하지 않음 | 사용하지 않음 | 17.07:1 |
| 어두움 | 잉크색 | 15.21:1 | 14.02:1 | 12.74:1 | 사용하지 않음 |
| 어두움 | 보조 글자색 | 7.36:1 | 6.79:1 | 6.17:1 | 사용하지 않음 |
| 어두움 | 잉크 바탕 위 글자 | 사용하지 않음 | 사용하지 않음 | 사용하지 않음 | 15.21:1 |

주요 버튼과 툴팁, 되돌리기 알림은 모두 `--color-on-ink` / `--color-ink` 조합이다. 주요 버튼의 호버도 같은 바탕을 유지하고, 되돌리기 글자 버튼의 호버는 투명 바탕과 알림 전용 글자색을 유지한다. 보조 버튼·아이콘·토픽 상자의 호버는 잉크색 또는 보조 글자색을 초안 면에 놓으므로 위 표에 포함된다. 비활성 보조 버튼도 보조 글자색을 면 위에 쓴다. 최저 대비는 밝은 모드 6.00:1, 어두운 모드 6.17:1이다.

실 색은 장식만 담당하므로 위 글자 대비 표의 전경색으로 사용하지 않는다. 프롬프트·스키마·기존 분류 규칙은 이 디자인 안내의 개편 대상이 아니다.

## 10. 완료 기록, 백업과 공유

완료 기록에는 완료 당시 카드 제목·토픽 이름·메모·완료 시각을 별도 스냅샷으로 남긴다. ‘지난 토픽’은 Asia/Seoul 날짜로 묶는다. 토픽을 삭제하거나 대화 결과를 다시 가져와 토픽 목록을 바꿔도 이 기록을 보존한다.

설정 화면의 ‘백업 → 내보내기’는 현재 모드의 토픽·카드·완료 기록 등을 Untangle JSON 백업으로 내려받는다. ‘가져오기’는 JSON 형식·백업 버전·저장 자료 구조를 먼저 검증하고 토픽 수·완료 기록 수를 담은 확인 창을 연다. ‘교체해서 가져오기’를 누를 때만 현재 모드를 교체한다. 개인과 샘플 백업은 서로 다른 모드에 넣을 수 없고 다른 모드의 자료도 덮어쓰지 않는다. 형식 오류나 취소 시 기존 자료를 유지하며 백업 복원만으로 LLM을 호출하지 않는다.

브라우저 탭 아이콘은 선 그림을 사용한다. 페이지별 제목과 공통 설명, 1200×630 공유 미리보기 이미지를 제공한다. 공유 이미지는 앱 이름·대표 문구·장식 선으로 만들며 개인 토픽이나 카드 내용을 포함하지 않는다.
